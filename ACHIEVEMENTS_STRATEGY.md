## 🎯 STEP-BY-STEP UNLOCK STRATEGY

### ⚡ QUICKDRAW — *Unlock in 5 minutes*

**What**: Close an issue or pull request within 5 minutes of opening it.

**How to unlock RIGHT NOW**:
1. Go to any of your repositories (e.g., `vedparkasharya` profile repo)
2. Click **Issues** tab → **New Issue**
3. Title: "Test issue for Quickdraw badge"
4. Click **Submit new issue**
5. **IMMEDIATELY** click **Close issue** (within 5 minutes)
6. Badge appears within 24 hours

**⚠️ Pro tip**: You can also do this with a Pull Request. Create PR → immediately close it.

---

### 🦈 PULL SHARK — *Unlock with 2 merged PRs*

**What**: Have 2 pull requests merged into repositories (not forks).

**How to unlock**:
1. Create a new branch in any of your repos: `git checkout -b feature/quickfix`
2. Make any small change (add a comment, fix a typo, update README)
3. Commit and push the branch
4. Open a Pull Request to merge into `main`
5. Merge the PR
6. Repeat steps 1-5 one more time

**Tier progression**:
- 🥉 Default: 2 PRs merged
- 🥈 Bronze: 16 PRs merged
- 🥇 Silver: 128 PRs merged
- 🏆 Gold: 1024 PRs merged

**Strategy**: Make small, meaningful PRs to your own repos daily. Document updates, fix typos, add features. You can also contribute to open-source projects!

---

### 😅 YOLO — *Merge without review*

**What**: Merge at least one pull request without code review.

**How to unlock**:
1. Create a new branch: `git checkout -b yolo/test`
2. Make a change and push
3. Create a Pull Request
4. **IMPORTANT**: Do NOT add any reviewers
5. Click **Merge pull request** directly (don't wait for review)
6. Confirm merge

**⚠️ Note**: This only works once. After you get it, you can't get it again.

### 🤝 PAIR EXTRAORDINAIRE — *Co-authored commits*

**What**: Have co-authored commits in merged pull requests.

**How to unlock**:
1. You need to make a commit with a co-author trailer
2. When committing, add this to the message:
   ```

   Co-authored-by: Friend Name <friend@example.com>
   ```
3. Push to a branch and create a PR
4. Merge the PR

**Tier progression**:
- 🥉 Default: 1 co-authored PR
- 🥈 Bronze: 10 co-authored PRs
- 🥇 Silver: 24 co-authored PRs
- 🏆 Gold: 48 co-authored PRs

**Strategy**: Collaborate with friends on projects. Each merged PR with co-authors counts. Use GitHub Desktop or command line with `Co-authored-by:` trailer.

## ⚠️ TROUBLESHOOTING

**Badge not appearing after meeting criteria?**

1. ⏰ **Wait 24 hours** — GitHub achievements have processing delay
2. 🔒 **Enable private contributions**:
   - Profile → Settings → Public Profile
   - Check "Include private contributions on my profile"
   - Check "Show Achievements on my profile"
3. 📧 **Verify email** — Git must use a verified email:
   ```bash
   git config user.email
   ```
   Make sure this email is verified in your GitHub account settings.
4. 🍴 **Forks don't count** — PRs in forks only count if merged into the parent repo
5. 🌿 **Default branch only** — Commits on non-default branches don't count until merged
