## 💡 Pro Tips for Each Achievement

### Pull Shark
1. Find `good-first-issue` labeled issues
2. Contribute to trending JavaScript/Python repos
3. Submit documentation fixes (easy merges)
4. Target repos with active maintainers

### Starstruck
1. Build developer tools (CLI, VS Code extensions)
2. Create awesome-lists (curated resources)
3. Share on Twitter, Reddit, HN
4. Ask friends and community to star

### Galaxy Brain
1. Enable Discussions on your repos
2. Answer in popular community repos
3. Provide detailed, code-rich answers
4. Follow up on your answers

### Pair Extraordinaire
1. Use `Co-authored-by:` in commits
2. Pair program with friends
3. Join open source pair programming sessions
4. Collaborate on group projects

### Quickdraw
1. Set up mobile notifications
2. Monitor your own repos closely
3. Create and immediately close test issues
4. Keep GitHub app open during active hours
