## How to Contribute

1. Fork the repository
2. Create a new branch (`git checkout -b feature/amazing-idea`)
3. Make your changes
4. Commit your changes (`git commit -m 'feat: add amazing idea'`)
5. Push to the branch (`git push origin feature/amazing-idea`)
6. Open a Pull Request

## Code of Conduct

- Be respectful and constructive
- Focus on meaningful improvements
- Follow existing code style
